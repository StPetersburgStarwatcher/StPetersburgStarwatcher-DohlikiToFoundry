# TokyoStargazer's VTMBuilder

Foundry VTT module (wod5e system) that goes with the VTM Builder.

**Install / update link** (Foundry → Add-on Modules → Install Module → Manifest URL):

```
https://github.com/StPetersburgStarwatcher/StPetersburgStarwatcher-DohlikiToFoundry/releases/latest/download/module.json
```

## Releasing an update

1. Replace the module files here with the new build and commit.
2. On GitHub: Releases → Draft a new release → new tag `vX.Y.Z` (higher than the last one) → Publish.
3. The *Release module* action attaches `module.zip` and `module.json` to the release (about a minute).
4. In Foundry: Add-on Modules → Check for Updates.
